# NL-COMP-002 — заранее отложенная контрольная серия (hold-out)

До запуска этой серии настройка коэффициентов AUTO фиксируется: 
`14.0 * number_of_patches * first_layer_width + downstream_dense_cost`, порог 70% предсказанной стоимости полного прохода. Она подобрана **только по первоначальной таблице** GCC из EXPERIMENT_PRE_REGISTRATION_RU.md. Измерения из текущего файла не допускается использовать для её настройки в этом исследовании.

Контрольные сети, не использованные при калибровке: 1536→192; 768→192→48; 256→96→24; 1024→128→64. Числа изменений за пакет: 2,8,24,48. 7 повторов, 256 вызовов на повтор, два компилятора GCC/Clang с OpenBLAS, один поток.

Метрики: медиана AUTO/FULL по каждому из 16 сценариев, количество пар с преимуществом >20%, количество сценариев, где AUTO хуже FULL более чем на 20%, максимальная нормированная численная ошибка (допуск 1e-9). В зависимости от размера и числа изменений должны присутствовать **и положительные, и отрицательные** результаты; не утверждать всеобщую победу. При >20% регрессии хотя бы в одном сценарии — считать выбор стратегии недостаточно надёжным и не утверждать его готовность к встраиванию как оптимальный.

Отдельно от этого — сравнение с настоящим Android ARM64 и сторонними фреймворками не проводилось.
