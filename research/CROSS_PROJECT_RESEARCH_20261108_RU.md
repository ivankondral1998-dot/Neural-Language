## Проекты из доступной истории ChatGPT (исторические сообщения, НЕ текущий GitHub-аудит)

- **PMB / PMB Agent Memory Lite:** сырой источник и производный handoff принципиально различны; происхождение, частичность восстановления, локальное сохранение и проверка целостности важнее заявления о «полной памяти». Для языка полезна идея явно описывать, какая часть состояния сохраняется/восстанавливается, и не выдавать резюме за исходные данные.
- **CELL:** независимый контур памяти LLM; опыт прерванной записи и восстановления указывает на необходимость транзакционных контрактов записи модели. Это **идея для будущих тестов**, не реализованная транзакционность Neural Language.
- **Jarvis Mobile, JNO, UNO:** модель может формировать решение, но доказательства результата и разрешение на действие должны проверяться отдельно; аналогия для будущей системы эффектов языка, не право добавить Android-команды.
- **MLBB Fenrir, NetworkClient:** воспроизводимые измерения, выбранная сеть/среда, статистика и provenance критичны при сравнении производительности. Применить к протоколам benchmark Neural Language без копирования сетевых алгоритмов.
- **Huawei ChatGPT Web:** без проверки на конкретном Android нельзя объявлять хостовую компиляцию подтверждением мобильной работы.
- **Iskra:** отдельное старое направление, не является базой Neural Language; из него ничего не переносилось.

## Решения для Neural Language (инженерные выводы, НЕ утверждения владельца)

| Пример/наблюдение | Применимое требование к языку | Что сделано сейчас |
| --- | --- | --- |
| UNO: память, веса и права — разные сущности | Семантика операций должна различать состояние входа, модель и внешние эффекты | Узкая статическая проверка наличия входа перед исполнением |
| PMB/CELL: сохранённое состояние, provenance, crash/restore | Для checkpoint/model I/O нужна явная модель состояния и отказов | Только задокументирован разрыв; runtime сохранения не меняли |
| Bodycam: статус обязан подтверждаться логом | Отдельно показывать «прочитано», «тестировано», «собрано», «на устройстве» | Логи и SHA включены в пакет; Android не проверялся |
| JarvisLab: отрицательные сценарии/независимый readback | Компилятор обязан предсказуемо отклонять недопустимый порядок операций | Негативные тесты неправильных программ |
| MLBB/NetworkClient: корректный baseline | Скорость языка не доказывается измерением старого медленного C++ | Бенчмарки и маркетинговые заявления не менялись |

**Запрет на неявный перенос:** чужие схемы, классы, лицензии, модели весов, защиты и правила агентов не копируются и не становятся требованиями Neural Language без отдельной обоснованной задачи. Все проекты кроме Neural Language оставлены без изменений.
