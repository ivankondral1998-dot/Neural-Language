# Какие прошлые исследования действительно полезны Neural Language

**Рамки:** чтение и концептуальное сравнение; чужие исходники, веса, модели, лицензии, инструкции и архитектуры **не копировались и не подключались** к Neural Language. Это выборочная оценка доступных материалов, не исчерпывающий аудит всех старых чатов и всех GitHub-веток.

## Что проверено

Сначала использован прежний обзор `research/CROSS_PROJECT_RESEARCH_20261108_RU.md` с перечнем **11 репозиториев, найденных в трёх подключённых аккаунтах**, и доступных AGENTS/README. Новый проход по сохранённой истории ChatGPT подтвердил направление проекта. Нынешнее изменение опирается исключительно на код **Neural Language** из ветки `fix/neural-ir-effects-20261108`; внешний GitHub код не копировался.

| Источник | Проверенное свидетельство или характер доступа | Применимое наблюдение (НЕ копирование) |
| --- | --- | --- |
| **Neural Language** | исходники компилятора, ядра и тестов в GitHub, текущий HEAD и Git blob проверены | ошибки типов/размеров должна отвергать граница **перед** генерацией C++ |
| **UNO / UNOVYRA** | действующий `AGENTS.md` и исторические исследования о памяти, весах, каузальных состояниях | отличать вес/состояние/результат и типизированные численные данные; не переносить архитектуру UNO или runtime-веса |
| **JarvisLab/JNO** | исторические AGENTS/README веток V21, отделение решения модели от разрешения и фактического результата | в IR явно различать контракт и проверенное последствие; Android-сервисы не являются операторами Neural Language |
| **Bodycam Diagnostics** | `AGENTS.md` и README, уровни `INSPECTED/TESTED/BUILT/DEVICE_VERIFIED` | IR-компиляция, тест C++ и тест на реальном телефоне имеют разные доказательства |
| **HuaweiChatGPTWeb** | доступный README/AGENTS в GitHub, сборка отдельно от испытаний на Huawei | нельзя приравнивать `clang++` на Linux к ARM64/Android |
| **PMB** | прежние описания и доступная история ChatGPT; исходники здесь не инспектировались | сохранённый RAW, handoff и неполная история различаются; по аналогии контракт IR нельзя принимать на доверии после мутации |
| **CELL** | история ChatGPT; GitHub `403` на приватном репозитории | provenance, прерывание записи, восстановление состояния — отдельная будущая задача; здесь не внедрялось |
| **NetworkClient** | история ChatGPT, GitHub `403` | для будущих бенчмарков фиксировать среду, сравнимый baseline и распределение измерений |
| **MLBB Fenrir** | история ChatGPT, GitHub `403` | средняя задержка не доказывает стабильность: нужны диапазоны, выбросы и A/B условия |
| **JarvisMobile, JarvisSpeechLab-Grok, Jarvis-Lab** | история/предыдущий список GitHub; доступ к актуальным приватным файлам ограничен `403` | автономность, безопасность, валидация на устройстве не доказываются только host-тестами |
| **Iskra** | старые исследования как независимое направление | **не** заменять новый `.nir` Python-DSL или средой Iskra |

Итог пересмотра: наиболее практически полезным на текущем этапе оказалось **повторно проверять границу между представленными данными и выполняемым действием**, вместо расширения языка новым видом нейронов. Это инженерный вывод по доступным источникам, **не** решение владельца о переносе архитектуры других проектов.

## Что умышленно не делалось

Не переносились чужие модули, алгоритмы Jarvis, данные CELL/PMB, веса UNO, GitHub workflows и исследовательские ограничения сторонних проектов. Не проводилась полная переоценка 0.4 DAG и 0.5 ассистента; они остаются отдельными экспериментальными ветками, не частью текущего ядра языка. Никакие репозитории кроме Neural Language не менялись.
