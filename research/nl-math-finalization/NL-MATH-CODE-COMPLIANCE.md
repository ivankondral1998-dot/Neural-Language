Для всех четырёх сравнений `language/runtime/neural_runtime.hpp` и `language/compiler.py` получены с закреплённого commit. На исследовательских runtime staging после локальных проверок демонстрирует намерение атомарной публикации слоёв, но утверждение о полном transactional state и всех исключениях здесь не доказано. `observe` сравнивает std::vector<double> по числовому равенству; следовательно signed-zero политика должна быть рассмотрена отдельно для каждого входного пути и наблюдений.

Текущая грамматика, NeuralIR/0.2 и проверка shapes/effects касаются ограниченных сетей, а не универсального tensor/AD registry. INT8 означает ограниченное хранение с legacy scale и rounding, не автоматически integer-dot с доказанным accumulator bound. Runtime и `.nir` не содержат описанного общего NL-CANON/1, общего training snapshot либо обученной системы helpers с независимым verifier. Это незавершённые функции, не доказанные ошибки существующих ограниченных операций.

Новые требования FINAL-SPEC следует трактовать как спецификацию цели подмножества, а не утверждать, что main уже ей соответствует. Численные тесты старых веток и аппаратные измерения из архивов не перенесены на другие HEAD. Дополнительные GCC/Clang runtime регрессии на этих четырёх HEAD в данном продолжении не выполнялись.
