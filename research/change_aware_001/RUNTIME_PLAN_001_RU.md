# NL-COMP-001B — расширение проверки: прямой runtime против OpenBLAS

Дата до запуска: 2026-11-08. Это отдельная регистрация, исходный план NL-COMP-001 не переписывается.
Обнаружен проверенный исходный `language/runtime/neural_runtime.hpp` 0.3 из архивной карты; его Git blob SHA `ee71cdab32b248814aa23f26318130bd155c824f` совпадает с действующим в main.

Более строгий тест: использовать ровно этот заголовок **без изменений**. Создать `neural::Model`, программно задать те же FP64-веса/вход/смещения, что в независимой экспериментальной сети, и вызвать публичные `Model::change()` / `Model::infer(false)`. Режимы `FULL`, `AUTO`, `DELTA` получают идентичную последовательность изменений. Сборка с `NEURAL_RUNTIME_SCIPY_BLAS` обязательно использует OpenBLAS.

Параметры: обе сети 128→256→32 / 256→512→128, слои 0/1, батчи 1/8/32/64, `reps=5, steps=250, warmup=32`, GCC и Clang, однопоточный OpenBLAS, исходный seed=20261108. Сопоставление с внешней OpenBLAS forward в каждом шаге, `relative<=1e-9`. В измерениях включены API-валидации/обновления через публичный runtime (важно для честной стоимости готовой реализации).

**Критерий** предварительного выигрыша: медиана runtime AUTO на 20% ниже runtime FULL, как минимум в 4/5 парных повторов; отдельное сравнение с прямым внешним OpenBLAS — дополнительная граница, оно имеет иную API-стоимость. Потеря >20%, несовпадение выходов, или отсутствие преимущества по двум компиляторам — негативный результат, не скрывать.

Не переносить отдельный экспериментальный алгоритм в production без дальнейших тестов. Этот тест не является Android/ARM64-бенчмарком и не доказывает новизну алгоритма.
