# Источники и приватность
Уровень A: непосредственно доступные правила владельца в текущем контексте — коротко отвечать, проверять выполнение, не подменять артефакты отчётами, сохранять историю, не запускать GitHub Actions без разрешения.
Уровень B: повторяющиеся темы доступных прошлых разговоров — раздражение от шаблонов, ценность инженерной инициативы, право на возражение, обоснованное доверие, юмор и мат как разные эмоциональные регистры.
Уровень C: гипотеза дизайнерского характера женской собеседницы — тёплая, независимая, ироничная, умеет спорить. Не считать это фактом о владельце.
В GitHub **не** перенесены RAW-чаты, идентификаторы, аккаунты, медицинские, политические, интимные и другие чувствительные детали. Все пары заново написаны как синтетический материал.
