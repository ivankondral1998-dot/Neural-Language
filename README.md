# Neural Language

Экспериментальный специализированный язык программирования для создания, обучения, проверки и оптимизации нейронных систем, разрабатываемый совместно с ИИ-агентами.

**Текущий статус:** интеграционный прототип **0.3 / CONDITIONAL**, не готовая платформа и не UNO.

**Цель владельца:** единая система «собственный язык + помощник» для нейронных весов, изменяемых связей, обучения, генерации исполняемого кода и проверяемой оптимизации, с перспективой эффективной работы на Android.

На этапе 0.3 применяется цепочка `.nir → Neural IR JSON → C++17 → GCC/Clang → native`. Язык не является самодостаточным машинным компилятором; производительность обеспечивается вычислительным C++-ядром. Встроенный помощник пока выбирает один из готовых режимов вычислений, а не переписывает код самостоятельно.

**Важно:** первоначальная структура репозитория создана 8 ноября 2026 года. До загрузки проверенного исходного пакета версии 0.3 этот репозиторий **не содержит исполняемую реализацию**. Не заявлять, что исходники уже доступны, пока они не загружены.

## Инженерные правила

- Не смешивать с UNO, Jarvis и «Искрой».
- Начинать с `AGENTS.md`, проверять актуальную ветку и SHA.
- Не удалять исходники и старые версии без разрешения владельца.
- Не запускать GitHub Actions без отдельного разрешения.
- Ускорение, точность и готовность подтверждать воспроизводимыми тестами; результаты локальных лабораторных замеров не выдавать за свойства языка или подтверждение Android.
- Любое изменение сохранять с возможностью отката.
