# Neural Language 0.1 — контракт языка (черновик реализации)

## Синтаксис

Новая исходная программа — UTF-8 текст в `.nir`:

```text
brain Example {
  senses 2
  neurons hidden 4 relu
  neurons result 1 sigmoid
  init 21
}
observe [1, 1]
predict
learn [1] rate 0.2
remember saved
weight hidden 0 1 add 0.1
edge hidden 0 1 off
tune incremental
predict
rewind saved
advise 200
report "example.json"
```

Ограничение версии: один `brain`, до восьми полносвязных слоёв. Идентификаторы — латинские буквы, цифры и подчёркивания. Комментарии начинаются с `#` в начале строки; вложенные блоки `cycle N { ... }` разрешены до глубины восьми. Ограничены размер модели и развёрнутый объём программы.

## Семантика нейронов

Нейронный слой: `z_i = bias_i + sum_j(mask_{ij} * weight_{ij} * input_j)`; активации `linear`, `relu`, `sigmoid`. Задание `neurons NAME M ACT` создаёт `M` выходных нейронов со всеми входными связями от предыдущего слоя. Инициализация весов — воспроизводимый генератор MT19937 в C++; распределение примерно равномерное от -0.35 до +0.35, начальные смещения 0.

`learn [target...] rate R` минимизирует квадратичную ошибку обычным обратным распространением по текущему `observe`. Градиенты вычисляются **перед обновлением весов**, отключённые связи исключены из градиентных операций и передачи сигналов. Это SGD, а не общий алгоритм непрерывного обучения.

`weight layer row col add delta`: локально меняет значение веса. `edge ... off`: маска связи 0, при `on` возвращается исходный вес; маска не удаляет память для веса. Каждая такая операция увеличивает монотонную версию состояния. Изменение веса или связи при допустимом кэше может использовать частичный пересчёт; новая `observe`, `learn`, `rewind` делают кэш недействительным. ReLU использует сохранённое значение предактивации до изменения, поэтому переход через 0 обрабатывается корректно.

`remember` копирует весовые матрицы, маски, вход и версию; `rewind` восстанавливает модель, увеличивает текущую версию и сбрасывает кэш. Повторный `remember` с тем же именем отклоняется, чтобы исходный снимок не был перезаписан. Нет фоновых действий, внешних команд или сетевого доступа в языке.

`advise`: запускает на клонированных моделях одинаковую последовательность небольших синтетических изменений, сравнивает вычисления методом полного пересчёта и инкрементальным методом, сверяет конечные выходы с допуском 1e-8. Выводит только исследовательскую рекомендацию; не меняет исходную программу и не применяет оптимизацию автоматически. Краткий одиночный тайминг не считается строгим научным сравнением.

## Встроенные ограничения и ошибки

Компилятор проверяет формы векторов и валидность индексов до генерации C++. Запрещены произвольный Python/C++ код, импорт библиотек через DSL, доступ к файловой системе кроме явного `report` с локальным именем файла. Выполнение завершается ненулевым кодом при ошибке. При совпадении имени `report` создаёт новое имя с числовым суффиксом; одновременные процессы всё ещё требуют раздельных каталогов исполнения.

Важный момент: DSL ограничивает доступные действия самой программы. Но созданный исполняемый файл не является полноценной песочницей ОС. При работе с недоверенными `.nir` используйте изоляцию и отдельный рабочий каталог.

## Что такое собственный язык здесь

Новый синтаксис, модель команд, анализ размеров, Neural IR, семантика весов/связей, обучение и выборочный пересчёт **уже реализованы**. Python используется для начального компилятора, C++17 для генерации и исполнения. Это допустимый способ реализации нового языка, но **не** полностью самостоятельная машинная платформа. Существующую «Искру» и её интерпретатор новая система не использует.

## Дополнение 0.2-review2: встроенная проверка `verify`

```text
observe [0.1, 0.2]
verify 100
```

`verify N` (2..2000) запускает детерминированное сравнение полной и частичной обработки на *изолированных копиях* текущей сети. Команда не переписывает веса оригинала; журнал получает запись о результате. Проверяются слой за слоем предактивации, активации, веса и маски. В отличие от `advise`, **не измеряет ускорение и не рекомендует сменить режим**. Случайная последовательность задана фиксированным seed; это ограниченный регрессионный тест двух путей одной реализации, не независимый математический oracle и не доказательство правильности обучения.

Числовая валидация NaN, Inf и значений вне поддерживаемого диапазона теперь включена и в release-сборке `-DNDEBUG`.

## Экспериментальное дополнение NL-TRAIN-002: обучение непрерывным целям

Новая конструкция в изолированной ветке `feature/nl-train-002-regression-20261110`:

```nir
brain VectorRegression {
  senses 2
  neurons out 2 linear
  init 42
}
train_data "targets.txt" samples 4 epochs 80 rate 0.1 seed 17 targets vector
save_model "weights.nlw"
```

Каждая строка `targets.txt` содержит ровно `senses` конечных FP64-значений входа, затем по одному конечному FP64-значению для каждого нейрона выходного слоя. `targets vector` разрешён только у `train_data`; если он не указан, прежний формат — целочисленная метка класса и входные признаки — остаётся неизменным. Векторный режим допускает один выход и выполняет канонический SGD с MSE, не новую функцию потерь. Численные ограничения и seed совпадают с действующим контрактом `train_data`; все данные читаются и проверяются до первого обновления весов. Многопроходное обучение хранит строки в памяти для детерминированного перемешивания.

Neural IR добавляет `target_mode: "vector"` исключительно для нового режима и типизированную сигнатуру `targets: f64[output_width]`. Старые IR и C++-выходы без флага не меняются. До полной регрессии и проверки на устройстве расширение остаётся экспериментальным.
