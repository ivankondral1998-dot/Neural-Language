# NL-COMP-004 — единый контракт эффектов и изменений входа

Дата: 08.11.2026. Ветка: \`feature/effects-changes-integration-20261108\`.
Статус: **реализовано и проверено на Linux x86-64; Android и общее DAG-представление не проверены**.

## Цель и обоснование

Продукт: Neural Language — специализированный язык программирования для нейронных вычислений, с будущим проверяемым преимуществом на телефонах. См. [продуктовый контракт](../NEURAL_LANGUAGE_PRODUCT_CHARTER.md).

Уже имелись два раздельных, противоречивых статических механизма:
- \`NeuralEffects/1\` в ветке \`fix/neural-ir-shapes-20261108\`: отслеживает входное состояние и снимки, включая восстановленный вход.
- \`NeuralChanges/1\` в NL-COMP-002/003: отслеживает \`observe_delta\`, но ошибочно считал **любой** \`rewind\` потерей входа.

Следствие: корректная программа \`observe → remember checkpoint → rewind checkpoint → observe_delta\` отвергалась компилятором, хотя реальный runtime восстанавливает сохранённый вход.

Вместо новой подсистемы **перенесён существующий контракт эффектов проекта и расширен одним оператором \`observe_delta\`**. Операции автоматически проверяются до генерации C++, а метаданные повторно проверяются на этапе \`emit\` и \`analyze_ir\`.

## Семантика

- \`observe\` делает вход доступным; \`observe_delta\`, \`predict\`, \`learn\`, \`expect\`, \`advise\`, \`verify\`, \`optimize\` требуют вход.
- \`remember label\` сохраняет признак наличия входа. \`rewind label\` восстанавливает именно сохранённый признак и все соответствующие численные данные runtime.
- Неизвестная метка, повторное использование имени снимка и создание снимка в цикле, повторяющемся более одного раза, отвергаются статически.
- Повторяющиеся циклы учитывают вторую итерацию для проверки состояния входа. Нет ветвлений, поэтому для текущей булевой модели переход стабилизируется за одну итерацию.
- \`validate\` проверяет модель на независимой копии и не создаёт вход в исходной модели.
- Словарь \`NeuralEffects/1\` расширен эффектом \`observe_delta\`: читает текущий вход, пишет текущий вход и кэш.
- \`NeuralChanges/1\` продолжает независимо проверять индекс, числовую дельту и происхождение операции. Проверка предусловий делегирована общему \`NeuralEffects/1\`, а не дублируется.

## Совместимость

Существующие допустимые \`.nir\` не требуют изменений синтаксиса. Дополнительное поле \`semantic_contract\` в Neural IR аддитивно. Старый IR без этого поля допускается при условии повторного анализа операций. Повреждённая метаинформация отвергается до кодогенерации.

Вместо исторического отказа **во время исполнения** \`predict\` без \`observe\` и повторные снимки теперь отклоняются **во время компиляции**. Соответствующие тесты обновлены по месту обнаружения ошибки, без изменения правил приёмки. Runtime не менялся.

Генерируемый C++ для девяти существующих примеров **побайтно совпал** с NL-COMP-003. Эталонные SHA-256 сохранены в \`language/tests/test_effects_changes_integration.py\`.
