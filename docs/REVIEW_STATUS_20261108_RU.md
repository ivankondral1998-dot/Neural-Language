## Реальное изменение

Добавлена статическая проверка обязательного входного состояния после парсинга `.nir` / до генерации C++.

- Вход обязателен для `predict`, `learn`, `expect`, `verify`, `advise`, `optimize`.
- `remember` / `rewind` учитывают признак наличия входа в снимке.
- `validate` проверяет на отдельной копии и **не** подменяет `observe`.
- `load_model` меняет веса модели, но **не** создаёт наблюдение.
- `cycle` учитывается с гарантированно положительным количеством итераций.

Изменены `language/compiler.py`, один устаревший тест `language/tests/test_language.py` (новый ожидаемый момент отказа), добавлены `language/tests/test_state_effects.py` и документы. `language/runtime/neural_runtime.hpp` не менялся.

## Границы результата

- Исправлен только один класс ошибок последовательности операций; математические алгоритмы и производительность не улучшены.
- Статический анализ не доказывает корректность `remember` с дублированными именами, файлового ввода, аварийного завершения, транзакционности модели и выделения RAM. Runtime остаётся ответственным за эти проверки.
- Нет запуска на Android, ARM64, реальных крупномасштабных сетях или доказательства преимущества над C++/MLIR.
- Список ChatGPT-проектов составлен по доступной истории, **не** является подтверждением актуального состояния их внешних репозиториев. Шесть GitHub-репозиториев вернули HTTP 403 при попытке читать README/AGENTS.
- Код/модели других проектов **не** использовались. Другие проекты и GitHub Actions не менялись/не запускались.

Следующий инженерный дефект для отдельного этапа: нормативная типизация Neural IR и эффекты над снимками/весами/вводом; не автоматически внедрять зависимости или создавать отдельные модели-помощники.
