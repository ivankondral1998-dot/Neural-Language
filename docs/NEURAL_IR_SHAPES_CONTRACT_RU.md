# Neural Language — контракт типов и форм Neural IR

**Дата:** 08.11.2026. **Этап:** последовательный `NeuralIR/0.2`, дополнительный `NeuralShapes/1`.

**Цель:** сделать существующую цепочку `.nir → Neural IR → C++17` безопаснее относительно ошибки формы, индекса и числа, **не** добавляя новую модель, нейронный оператор, отдельного агента или переписывание runtime.

## Наблюдаемая проблема до изменения

Парсер `.nir` проверял размеры и диапазоны, но `emit(ir)` мог получить уже изменённый Python-словарь IR. После этого короткий входной вектор, некорректный индекс веса, `NaN`, изменённый размер нейронного слоя, подменённое имя или путь могли пройти в генератор C++ либо вызвать некорректную интерпретацию. До исправления новые тесты воспроизвели эти отказы.

## Контракт `NeuralShapes/1`

Этот контракт **ограничен последовательными полносвязными слоями** исходного языка 0.3. Типы: `f64` для входных/выходных векторов; физическое хранение весов `float` или `int8` сохраняется отдельно. INT8 не означает, что арифметика или процесс обучения выполняется целиком в INT8.

Пример компактных полей `shape_contract`, добавляемых к уже существующему IR:

```json
{
  "version": "NeuralShapes/1",
  "input": {"dtype":"f64", "shape":[2]},
  "output": {"dtype":"f64", "shape":[1]},
  "layers": [
    {"name":"hidden", "input":{"dtype":"f64", "shape":[2]},
     "output":{"dtype":"f64", "shape":[3]}, "weight_shape":[3,2], "weight_storage":"int8"},
    {"name":"output", "input":{"dtype":"f64", "shape":[3]},
     "output":{"dtype":"f64", "shape":[1]}, "weight_shape":[1,3], "weight_storage":"float"}
  ],
  "operation_signatures": {
    "observe": {"values":{"dtype":"f64", "shape":[2]}},
    "learn": {"values":{"dtype":"f64", "shape":[1]}, "rate":"f64"}
  }
}
```

Это **иллюстративный фрагмент**: действительный контракт также содержит поле `scope` и сигнатуры всех встречающихся операторов с типизированными аргументами. Серийный JSON не заменяет C++ runtime, память GPU или типизированный общий тензорный IR.

## Проверки перед генерацией C++

`verify_typed_ir(ir)` независимо проверяет:

1. Версию `NeuralIR/0.2`, имя модели, входной размер, seed, последовательные слои, их уникальные имена, активацию и storage.
2. Формы матриц `[выходы, входы]`, выходную размерность, пересчёт `weights`, `macs`, `storage_bytes`, `weight_bytes` и соответствие заданному статическому бюджету.
3. Векторы `observe`, `learn`, `expect`, `validate`; скалярные параметры, диапазоны и отсутствие `NaN`, `Inf`, булевых значений вместо чисел и чисел вне допустимого диапазона.
4. Существование слоёв и границы индексов `weight` / `edge`.
5. Форму циклов, ограничение глубины/числа шагов, допустимость enum, seed, идентификаторов и локальных имён файлов.
6. Согласованность `estimated_max_operations` и объявленного `shape_contract` с фактическим IR.

`emit()` повторно вызывает **и** проверку типов/форм, **и** существующую проверку состояния и эффектов `NeuralEffects/1`. `analyze_ir()` также проверяет обе перед расчётом рекомендаций. Если `shape_contract` отсутствует у старого словаря Neural IR, данные всё равно перепроверяются: отсутствие метаданных не является обходом проверки. Подменённый `shape_contract` отклоняется.

## Совместимость и границы

- Не изменены грамматика `.nir`, набор операций, C++ runtime, алгоритмы обучения, способ хранения весов, порядок вычислений.
- У всех семи старых примеров исходные поля IR **совпадают** с предыдущим компилятором; генерируемый C++ совпадает **побайтно**. Новое поле `shape_contract` — аддитивное расширение JSON.
- **Не реализованы:** общий тензорный язык с ранговыми формами, tensor broadcasting, attention, графы 0.4 DAG, математическое доказательство всех путей backprop, оптимизирующие IR passes, гарантированная RAM, безопасность недоверенного C++-бинарника, Android/ARM64, самохостинг.
- Статический `budget` по-прежнему **не** является лимитом реальной RAM/RSS. Доверенность модели `.nlw` и безопасность ОС этим изменением не обеспечены.
- Это проверка API генератора, принимающего Python-словарь IR, а **не** новая CLI-функция импортирования произвольного внешнего JSON.

## Тестирование

- Новые тесты `language/tests/test_typed_ir.py`: ошибочные векторы, `NaN/Inf`, инъекции в идентификаторы/имена файлов, индексы, модельные totals, бюджет, циклы, проверка метаданных, JSON round-trip и backward compatibility.
- 350 детерминированных конфигураций нейросетей сверены с независимыми формулами количества весов и размеров памяти; неправильный target в каждой из них отвергнут.
- Семь ранее существовавших `.nir` сравнены с компилятором предыдущей ветки без переинтерпретации операций.
- Сквозное обучение → сохранение → загрузка → вычисление проверено через GCC и Clang, весовой файл дополнительно пересчитан независимым Python-эталоном.

**Позиционирование:** это шаг к строгой семантике собственного специализированного языка, но не доказательство превосходства над существующими ML-компиляторами.
