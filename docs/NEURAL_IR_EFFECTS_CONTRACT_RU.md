# Neural Language — статический контракт эффектов Neural IR

**Ревизия:** 2026-11-08. **Исходная контрольная точка:** `fix/static-input-state-20261108`, `3b6c24b3f650ac3058bd50f1a12a3029a5e4b46a`. **Область изменений:** семантическая проверка языка и генерируемая метаинформация IR. Проекты UNO, Jarvis, CELL, PMB и сторонний код не используются в реализации.

## Назначение

Следующий ограниченный этап разработки специализированного языка для ИИ: фиксировать и проверять, **что команда читает, что может изменить и какие предварительные состояния обязательны**. Без новых нейронных операторов, сторонних моделей, помощников-разработчиков и изменений C++-алгоритмов.

Ранее `validate_input_state` проверял наличие `observe`, но не отвергал заведомо несуществующий `rewind`, дублирование снимка и снимок в повторяющемся цикле. Анализ только первой итерации также мог пропустить `predict` на второй итерации, если тело удаляло вход. Все четыре контрпримера перед изменением обнаружены новыми тестами.

## Проверяемые правила языка

1. **Входное состояние:** первоначально вход не задан. `observe` делает его доступным. `predict`, `learn`, `expect`, `advise`, `verify`, `optimize` требуют вход. `validate` проверяет на копии и **не** создаёт текущий вход. `load_model` загружает веса и **не** создаёт вход.
2. **Снимки `remember`:** имя должно быть уникальным во всём выполнении. Снимки сохраняются после `rewind`, не перезаписываются. Всего допустимо не более 64 снимков, как и в существующем C++ runtime.
3. **Восстановление `rewind`:** метка должна существовать к моменту обращения. Восстановление возвращает вместе с весами и масками признак наличия входа и само входное значение. Режим вычислений и журнал событий в снимок не входят.
4. **Циклы `cycle`:** количество итераций положительное и известно при компиляции. Поэтому определение снимка внутри повторяющегося цикла гарантированно попыталось бы повторить имя и отклоняется на этапе компиляции. Отдельно проверяется вторая итерация на нарушение требования входа: первый проход может убрать вход и создать ошибку лишь при следующем проходе. При текущем языке без ветвлений преобразование булева `input_bound` за одно тело — тождество или константа, поэтому для состояний входа достаточно двух проходов. Это **не** доказательство всех свойств произвольной будущей IR.
5. **Сохранение:** `save_model` и `report` имеют потенциальный эффект записи в файловую систему; `load_model` — чтения. Никаких гарантий атомарности и изоляции файловой системы данный контракт не добавляет.

## Формат внутри Neural IR

К `NeuralIR/0.2` добавлено необязательное поле `semantic_contract` со своей независимой версией `NeuralEffects/1`. Существующие ключи и формат операций остаются прежними. В поле находятся `initial_state`, `final_state`, `checkpoints`, `snapshot_count`, развёрнутые `operation_counts`, и `effects` с `requires`, `reads`, `writes`, `filesystem`. Значения `writes` — **возможный эффект успешного вызова**, не обязательное изменение. Условия ошибок исполнения, например переполнение числа и ошибки файлов, остаются в runtime.

Пример оператора:

```json
"validate": {
  "requires": [],
  "reads": ["model_parameters"],
  "writes": ["event_log", "stdout"],
  "filesystem": null
}
```

Генератор `emit()` повторно вызывает семантический анализ IR. Если операции были изменены после `parse()`, он отвергнет недопустимую последовательность. Если объявленное поле `semantic_contract` расходится с вычисленным из операций, генерация прекращается. Старые словари IR **без** поля принимаются с дополнительной проверкой состояния/снимков. **Это не полная структурная верификация внешнего IR JSON:** формы, типы и корректность всех произвольных JSON-полей не доказываются данным проходом.

## Приёмочные примеры

**Ошибки на этапе компиляции:**

```nir
brain Example {
  senses 1
  neurons output 1 linear
}
rewind unknown
```

```nir
brain Example {
  senses 1
  neurons output 1 linear
}
cycle 2 {
  remember same
}
```

**Корректное выполнение:**

```nir
brain Example {
  senses 1
  neurons output 1 linear
}
observe [1]
remember initial
cycle 3 {
  learn [0] rate 0.1
  rewind initial
}
predict
```

## Пределы проверки

- Доказана только узкая статическая корректность входного состояния и имён снимков для существующего детерминированного синтаксиса. Чистота `validate` зависит от C++ runtime и была проверена прежними тестами; не доказывается теоремой.
- Метаинформация о чтении и записи — консервативная база для будущих анализаторов, не самостоятельный оптимизирующий компилятор, не гарантия потока данных и не ABI системы типов.
- Тесты охватывают ограниченные сети и хост Linux x86-64; Android, нагрузки с большими моделями, квантованное обучение и конкурентное изменение весов остаются непроверенными.
- Никаких данных или кода из других проектов не перенесено. Все изменения применены только к Neural Language.
