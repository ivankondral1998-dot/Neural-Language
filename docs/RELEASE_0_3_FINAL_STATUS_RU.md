# Контрольная точка: Neural Language 0.3 integration

**Утверждённая владельцем цель не меняется:** специализированный язык для ИИ и единый помощник разработки, который использует этот язык. Первая законченная демонстрация цепочки, не полная реализация цели.

**Вход:** отдельная копия кода Neural Language 0.2 из `NEURAL_RESEARCH_AUDIT_FIX_20261108.zip`. Оригиналы оставлены неизменёнными, базовые SHA записаны в `baseline/BASELINE_SHA256.txt`.

**Изменения:**

- В компиляторе `.nir`: `validate`, `optimize`, `save_model`, `load_model`, IR и генерация C++17 для них.
- В runtime: read-only внешняя проверка на копии, осторожный выбор FULL/AUTO без изменения весов, сохранение и загрузка FP64/INT8 весов, смещений, масок, режима.
- Два отдельных исполняемых файла: тренировка и инференс без повторного обучения.
- Стенд самостоятельного прогона `run.sh`, независимая линейная проверка `oracle_integration.py`, негативные тесты на плохую модель и неправильную проверочную цель.

**Фактически выполнено в этой сессии:**

- `tests.test_language`: 22/22 PASS, отдельный завершённый прогон.
- `tests.test_quantization_fixes tests.test_verifier`: 10/10 PASS, отдельный завершённый прогон.
- `tests.test_hardening`: 8/8 PASS, отдельный завершённый прогон.
- `tests.test_integration`: 14/14 PASS, отдельный завершённый прогон.
- Сквозная сборка 2 нативных бинарников GCC (а также компиляция через Clang в новых тестах), обучение 1600 шагов, две holdout-проверки, `verify`, `optimize`, `trained.nlw`, загрузка и предсказание: PASS.
- Отдельный Python-эталон прочитал `trained.nlw` и независимо вычислил две контрольные точки: PASS.
- Дополнительный профиль более крупной сети через Clang вызвал `optimize` и получил `AUTO`, результаты внутри сравнения эквивалентны по заданной погрешности. Это не независимый performance claim.

**Не выполнено/не доказано:** Android, память и энергия, долговременное обучение, качество INT8 SGD, машинный компилятор без C++ bootstrap, самостоятельное изменение кода помощником, широкая оптимальность AUTO, превосходство над C++ или промышленными компиляторами. Benchmark и oracle ограничены явно указанными задачами. Исходный `run.sh` собирает из кода; готовые Linux binaries не подходят автоматически для Android.

**Вердикт:** `PARTIAL PASS` относительно полной цели / `PASS` относительно узкого интеграционного smoke test. Расширение языка требует будущей отдельной проверки целесообразности; это не утверждение архитектурного baseline для UNO.
