# Neural Language 0.3 — интеграционный прототип

**Статус: HOST-TESTED / CONDITIONAL.** Это не готовая платформа разработки ИИ и не UNO. Изменения в исходные репозитории пользователя не вносились. Исходник — исправленная копия Neural Language 0.2 из независимого аудита 08.11.2026.

## Что собрано

Единая `.nir`-программа `language/examples/integrated.nir` задаёт сеть и веса, обучает её на четырёх учебных примерах, проверяет на двух других, вызывает встроенные численные проверки и подбор режима вычислений, сохраняет веса в `trained.nlw`. **Другая скомпилированная `.nir`-программа** `language/examples/inference.nir` загружает сохранённые веса и выполняет предсказание **без обучения**.

Введены четыре команды:

- `validate [x...] target [y...] tolerance e` — проверка заявленного примера на отдельной копии сети; неверный результат останавливает программу, оригинальные веса не меняются. Автор обязан исключить эти примеры из обучения.
- `optimize N` — встроенный native-помощник сравнивает `FULL` и `AUTO` на одной синтетической нагрузке (изменение весов одного слоя), сверяет все выходы, три раза измеряет скорость и выбирает режим при явном выигрыше. **Меняет только режим исполнения, не веса и не код.** Никаких обещаний ускорения на неизвестных задачах.
- `save_model "trained.nlw"` — записывает веса, смещения, маски и режим работы в локальный текстовый формат `NLMODEL2`. Старые файлы не перезаписывает, использует суффикс при совпадении имени.
- `load_model "trained.nlw"` — восстанавливает эту модель в другую `.nir`-программу той же архитектуры. Проверяет форму и значения до применения. **Принимать следует только доверенные файлы**.

Путь: `.nir` → проверяемый Neural IR JSON → генерация C++17 → компиляция GCC/Clang → native executable. Python — только bootstrap-компилятор и внешние тесты; сам исполняемый файл не использует Python или сеть. Встроенный помощник реализован в C++ runtime и вызывается из `.nir`; это **не самообучающийся агент** и не самодостаточный компилятор машинного кода.

## Запуск

Требуется Linux x86-64, Python 3, GCC или Clang с поддержкой C++17. BLAS **не обязателен**.

```
bash run.sh
```

Скрипт создаёт новую папку `runs/run_XXXXXX`, компилирует оба `.nir`, запускает обучение и самостоятельную inference-программу; сохраняет `trained.nlw`, отчёты и логи. Старые папки не перезаписываются. Можно выбрать компилятор: `CXX=clang++ bash run.sh`.

Независимая проверка линейной формулы (только демонстрационная сеть):

```
python3 oracle_integration.py runs/run_XXXXXX/trained.nlw
```

Новые тесты:

```
cd language
python3 -m unittest -q tests.test_integration
```

Старые тесты можно запускать отдельно:

```
python3 -m unittest -q tests.test_language
python3 -m unittest -q tests.test_quantization_fixes tests.test_verifier
python3 -m unittest -q tests.test_hardening
```

## Фактические результаты и границы

- Демонстрация — **линейное приближение к заданной функции** на двух входах. Она не доказывает обучение общему интеллекту, качество сложной нейросети или переносимость.
- Обучение: четыре угловых примера, две точки проверяются отдельно; выход должен быть примерно 0.3 и 0.52. Независимый Python-расчёт читает веса из модели и заново считает те же две точки.
- Помощник выбирает FULL на маленькой сети и может выбрать AUTO на большой сети при небольших правках. Это выбор между уже существующими путями, не генерация новых алгоритмов и не поиск оптимальных весов.
- Расход ресурсов ограничен лишь статической оценкой числовых тензоров/MAC на один forward. **Нет предельной гарантии RAM, времени или энергии.**
- Запись отчётов/моделей в доверенной рабочей папке не даёт безопасности от гонок файловой системы. Нет загрузки произвольных сторонних `.nlw` без проверки. Модельный формат `NLMODEL2` не претендует на стабильный публичный ABI.
- Сохраняются только веса, смещения, маски, выбранный режим. Не сохраняются optimizer states, история checkpoints, состояние произвольного обучения или временные вычислительные кэши.
- Встроенный `verify` сравнивает два режима одного C++-ядра и **не** доказывает общую корректность. Независимый Python oracle в этом пакете проверяет лишь простую линейную задачу.
- Нет Android/ARM64 испытаний, непрерывного обучения, автоматического переписывания кода, доказанного превосходства над существующими фреймворками и полноценного ИИ-агента.

**Приёмочный статус:** один законченный сквозной путь есть; универсальная технология для разработки ИИ — **не готова**.
