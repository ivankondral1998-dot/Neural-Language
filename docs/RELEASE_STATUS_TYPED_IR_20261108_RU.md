# Neural Language — результаты ревизии типизации IR, 08.11.2026

**Статус: HOST-TESTED, ограниченный этап.** Изменены компилятор и тесты. Нейронная математика, C++ runtime, синтаксис `.nir` и весовые форматы не менялись. Из других проектов исходники/веса не переносились.

**База:** `fix/neural-ir-effects-20261108`, HEAD `1bec6b678709c8bdb2ca6232779fd4669b311d23`.

## Исправленный дефект

Промежуточное представление `NeuralIR/0.2` после разбора `.nir` могло быть изменено без повторной проверки формы перед `emit()`. В новом коде `verify_typed_ir()` проверяет структурную модель, скаляры, rank-1 векторы, индексы и бюджеты, формирует аддитивный `NeuralShapes/1`. `emit()` и `analyze_ir()` его повторно вызывают, включая при отсутствии метаданных у старого словаря IR. Контракт эффектов `NeuralEffects/1` сохраняется.

## Доказательства

- До изменения компилятора черновик нового набора выявил **17 отказов и 3 ошибки тестов** (среди них 3 обращения к ещё отсутствующему полю `shape_contract`), 2 проверки прошли. Это не результат PASS; красный лог сохранён в `evidence/typed_ir_red.log`.
- После изменения и расширения тестов `tests.test_typed_ir`: **20/20 PASS**. Включает 350 воспроизводимых конфигураций сетей, сверку форм с независимыми арифметическими формулами, порчу векторов/индексов/метаданных, опасные имена и численные аномалии.
- Окончательные группы: **75 + 8 + 14 + 6 + 2 + 1 + 1 = 107 тестов PASS**, каждая группа завершилась. Перечень и хэши логов — `evidence/TYPED_IR_MANIFEST.json`.
- Все **7/7** исходных `.nir`-примеров сохранили прежние поля Neural IR и **побайтно идентичный C++** по сравнению с предыдущим компилятором; добавлено только поле `shape_contract`. Подробности — `evidence/compat_7_examples_typed_ir.json`.
- Полный нативный цикл `train → save → load → infer` завершён с GCC и Clang. Независимый Python-расчёт по сохранённым весам — PASS.
- Исходный C++ runtime остался с Git blob `ee71cdab32b248814aa23f26318130bd155c824f`.

**Отчётность:** прежний общий запуск численных тестов превысил лимит и **не засчитан**. Каждый численный тест отдельно завершился успешно. Результаты не доказывают корректность всех возможных программ.

## Не реализовано

Полная тензорная типизация с динамическими формами, DAG 0.4 в основном языковом ядре, attention, оптимизационные IR-проходы, Android/ARM64, учёт реального RSS, самостоятельный AI-разработчик, превосходство над C++/MLIR/BLAS, безопасность запуска недоверенного кода. Перечисленное **не объявляется сделанным**.

**Следующий инженерный пробел:** нет независимого типизированного IR-интерфейса для доказуемо корректных преобразований и оптимизаций; прежде чем его вводить, нужен конкретный измеримый языковой кейс. Побочные ветки не сливаются автоматически.
