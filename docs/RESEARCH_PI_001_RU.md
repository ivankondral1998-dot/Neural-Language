# Neural Language — PI-001: проверяемые гипотезы о π и фазовых вычислениях

Статус: **RESEARCH / NO ACCEPTED ADVANTAGE**. Дата: 2026-11-08.
Это исследовательский реестр, **не** спецификация нового оператора языка, не решение менять архитектуру и не доказательство превосходства на телефонах.
Подчиняется [продуктовому контракту](../NEURAL_LANGUAGE_PRODUCT_CHARTER.md).

## Что здесь означает π

`π≈3.14159` — константа. Число `2` в заявленном OpenAI результате `μ(π)=2` — показатель иррациональности, **не** значение π и **не** число бит/весов/шагов обучения.

Релиз: OpenAI, *The irrationality exponent of π is 2*, дата рукописи 2026-09-24.
Источники:
- https://github.com/openai/math/tree/main/preprints/The-irrationality-exponent-of-pi-is-2-September-24-2026
- https://github.com/openai/math/blob/main/lean/docs/017.md

Показатель определяет **асимптотическую** возможность рациональных приближений `p/q`. Заявленное доказательство не даёт вычислимого общего порога `Q(ν)`, с которого начинается неравенство. Следовательно, оно само по себе **не** предоставляет конечной вычислительной гарантии для FP16/FP32/INT8, ускорения ARM64, новых весов, сжатия памяти или обучения. Машинная формализация математического утверждения также не доказывает корректности нашего C++ runtime.

## Исследовательская гипотеза PI-001A: компактное периодическое представление

Идея: в определённых задачах заменять представление части входного сигнала на фазовые/периодические признаки, например `[sin(2π f x), cos(2π f x)]`.

**Предшественники (известные решения):**
- Tancik et al., *Fourier Features Let Networks Learn High Frequency Functions in Low Dimensional Domains*, NeurIPS 2020. https://arxiv.org/abs/2006.10739
- Sitzmann et al., *Implicit Neural Representations with Periodic Activation Functions (SIREN)*, NeurIPS 2020. https://arxiv.org/abs/2006.09661

Известный математический механизм здесь — **не наше изобретение**. Проект должен установить конкретное дополнительное преимущество **языковой семантики, компиляции или исполнения** на мобильном CPU, которого не даёт обычная библиотека признаков.

**Фальсифицируемая постановка:** фиксировать семейства периодических и непериодических задач, одинаковые train/test splits и бюджет ресурсов. Сравнить прежний Neural Language, независимую хорошо настроенную реализацию Fourier Features/SIREN, обычную MLP и возможную экспериментальную трансформацию Neural IR. Сравнивать ошибку на неиспользованных данных, число параметров, стоимость подготовки признаков, latency, RSS и энергию на конкретном ARM64-телефоне. Не сравнивать улучшенную реализацию только со слабой старой версией проекта.

**Отказ:** если новый синтаксис просто вызывает `sin/cos` и не улучшает точность/издержки/безопасность относительно доступной библиотеки при равных условиях, не расширять основной язык. Если выигрыш наблюдается только на периодическом синтетическом сигнале, не обобщать его на ИИ в целом.

## Исследовательская гипотеза PI-001B: изменение фазового состояния как первичный эффект языка

Идея: проверять, может ли Neural IR выразить и корректно оптимизировать обновление фазового состояния `z=(cos θ,sin θ)` при изменении `Δ`, не вычисляя тригонометрические функции с нуля после каждого шага:

`(c',s')=(c cosΔ - s sinΔ, s cosΔ + c sinΔ)`.

Для постоянного шага `Δ` коэффициенты можно заранее вычислить один раз. Это **обычная известная рекуррентная формула поворота**, не принципиально новый алгоритм. Нужно анализировать накопление численной ошибки, частоту перенормировки, поведение при произвольных `Δ`, стоимость ветвлений и выигрыш против оптимизированной реализации той же рекурсии в C++/NEON, а не против наивного повторного вызова `sin` и `cos`.

**Особое требование:** недопустимо заявлять, что иррациональность π гарантирует неповторение фаз на конечном телефоне; пространство чисел конечной точности имеет конечное число состояний.

**Отказ:** если компилятор не даёт преимущества на равной рекурсии либо гарантии ошибки не удовлетворяют выбранной задаче, не включать оператор в язык.

## Исследовательская гипотеза PI-001C: формально проверяемые преобразования

Гарантии корректности переходов Neural IR могут быть полезны сами по себе, но напрямую **не следуют из `μ(π)=2`**. Возможная проверка: узкое преобразование, доказанное для математической модели, независимое исполнение на FP64/FP32 и анализ округления. Не считать теорему о π готовым доказательством для нашего компилятора. Работы по формальной верификации компиляторов и MLIR — отдельные аналоги.

## Решение и ограничения

**РЕЗУЛЬТАТ:** на 2026-11-08 в Neural Language **нет** измеренного π-специфичного ускорения и нет принятого фазового оператора. Зафиксированы три гипотезы, аналоги, критерии проверки и условия отказа. Это не реализация.

**Следующий допустимый шаг:** отдельно собрать минимальную воспроизводимую численную проверку PI-001B (разные `Δ`, FP64/FP32, ошибка по независимому эталону, без заявления о мобильном ускорении), затем — честный ARM64-бенчмарк с оптимизированным конкурентом. Только после результатов принимать решение об изменении языка.

Установление нового научного результата о π **не является** критерием завершённости Neural Language.
